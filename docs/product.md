# Описание Продукта: Telegram-бот для анализа здоровья

## Суть продукта
Telegram-бот, выступающий в роли "цифрового медицинского ассистента". Сервис принимает медицинские документы (анализы, выписки), анализирует их с помощью LLM (Large Language Model) и предоставляет пользователю понятную интерпретацию состояния его здоровья.

**Главная метафора:** Передать человеку в руки "пульт управления от его здоровья".

## Проблематика
*   **Хаос в документах:** Пользователи хранят множество бумажных документов, которые теряются и путаются.
*   **Отсутствие истории:** Сложно отследить динамику показателей и вспомнить даты последних обследований.
*   **Фрагментация:** Данные разбросаны по разным клиникам, теряется общий контекст для врача.
*   **Непонимание:** Сложные медицинские термины требуют простого объяснения ("перевода" на человеческий язык).

## Ценность (Value Proposition)
1.  **Оцифровка и порядок:** Единое хранилище для всех медицинских данных, структурированное и доступное всегда.
2.  **Ясность:** LLM превращает сложные медицинские отчеты в понятное саммари.
3.  **Контекст:** Возможность предоставить врачу полную картину здоровья, собранную из разных источников.
4.  **Контроль:** Пользователь всегда знает, что происходит с его организмом, без необходимости разбираться в бумагах.

## Глобальный User Flow

1.  **Onboarding (Квиз):**
    *   Пользователь проходит серию вопросов с вариантами ответов для первичного сбора анамнеза и контекста.

2.  **Сбор данных (Upload):**
    *   Пользователь загружает фото или файлы медицинских документов.
    *   Система поддерживает загрузку нескольких файлов до определенного лимита.

3.  **Анализ (Magic):**
    *   Визуализированный процесс обработки данных (LLM анализирует содержимое).

4.  **Первичный результат:**
    *   Пользователь получает краткое саммари (summary) анализа.

5.  **Пэйволл (Monetization Point):**
    *   Предложение расширенного функционала:
        *   Детальный фидбэк/развернутая интерпретация.
        *   Сохранение данных в "Карточку пациента" (долгосрочное хранение и структурирование).
    *   **Модель:** Подписка.

6.  **Полный доступ:**
    *   После оплаты открывается доступ к "Карточке пациента", истории анализов и детальным рекомендациям.
